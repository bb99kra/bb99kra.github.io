# Claude AI - 100% Client-Side Web Replica

> Live Site: [https://bb99kra.github.io](https://bb99kra.github.io)

An identical, high-fidelity replica of Anthropic's **Claude.ai** interface, built as a pure client-side single-page application (SPA) hosted on GitHub Pages.

---

## ✨ Features

- 🎨 **100% Claude.ai Interface**: Signature Claude terracotta styling, warm ivory linen light theme & obsidian dark theme, Copernicus serif typography, sleek pill buttons.
- ⚡ **Artifacts 2.0 Studio**: Interactive side-by-side split screen for live-rendered HTML/CSS/JS web apps, SVGs, diagrams, and code snippets.
- 📁 **Workspaces / Projects**: Create custom project workspaces with dedicated custom system prompts and uploaded knowledge documents.
- 🧩 **Claude Skills System**: Pre-installed skills (Artifacts, Web Search, Code Sandbox, Lenient Mode) plus the ability to create unlimited custom skills.
- 🌐 **Live Web Access**: Real-time internet queries via Jina AI search reader (`s.jina.ai`) with citations.
- 🔓 **Lenient / Unrestricted Developer Mode**: Built-in toggle to bypass moralizing refusals and obtain direct, comprehensive technical & creative outputs.
- 🔌 **Multi-Provider API Support**:
  - **Anthropic Claude Native API** (`/v1/messages`)
  - **OpenAI-Compatible APIs** (`/v1/chat/completions`) for OpenRouter, DeepSeek, Groq, OpenAI, Ollama, and custom proxies.
- 🔒 **100% Private & Local**: Zero backend server, API keys and chats are stored strictly in browser `localStorage`.
